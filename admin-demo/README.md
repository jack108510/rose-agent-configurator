# Atlas SaaS workspace

A fictional automation SaaS dashboard with the actual Rose website widget in its normal bottom-right corner. The application itself contains no Rose marketing, assistant sidebar, demo banner or scripted chat. Metrics and workspace actions use synthetic data.

`rose-widget.js` is the unchanged live runtime retrieved from the existing Harbourlight Rose installation on November 16, 2026. It uses the live Rose pilot chat/voice service, native appearance and floating launcher. `rose-bridge.js` selects the service’s existing isolated prospect-preview mode. No backend software was rebuilt and no live account or external integration is changed.
